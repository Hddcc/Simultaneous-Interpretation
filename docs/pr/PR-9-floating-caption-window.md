# Add floating caption window

## 功能描述

本次变更新增悬浮字幕窗口。用户可以在主工作台打开或关闭悬浮字幕，并选择紧凑、标准、宽屏三种尺寸，以及左上、右上、左下、右下四个屏幕位置。

悬浮窗口会保持在其他应用上方，实时同步当前译文、原文、语言方向、输入状态、字幕延迟和修订状态，适合用户观看浏览器网课、会议窗口或视频播放器时持续阅读字幕。

## 实现思路

- Electron 主进程新增第二个 `BrowserWindow`，使用同一个 Vite 页面并通过查询参数渲染悬浮字幕模式。
- preload 新增悬浮窗打开、关闭、配置和字幕状态同步 API。
- 主工作台维护当前字幕状态，并通过 IPC 将状态广播给悬浮窗口。
- 主工作台新增悬浮字幕控制区，用于调整窗口尺寸和屏幕角落位置。
- 悬浮窗口使用独立样式，突出译文并保留原文和基础状态。

## 验证方式

- 运行 `npm run build`，确认 TypeScript、Electron 主进程和 Vite 构建通过。
- 运行 Electron smoke test，确认桌面应用可以启动并保持运行。
- 运行 `openspec validate --all`，确认 OpenSpec 变更仍然有效。
- 在桌面应用中打开悬浮字幕，切换尺寸和位置，确认窗口保持可见并同步当前字幕。

## 范围说明

本次只实现悬浮字幕窗口和主工作台控制。可选 TTS、最终 demo 文档和提交检查会在后续独立变更中完成。
