# Add bilingual translation pipeline

## 功能描述

本次变更新增中英双向翻译链路。用户可以选择“英语 -> 中文”或“中文 -> 英语”，应用会保存上次选择，并在稳定 ASR 片段出现后生成对应译文字幕。

主字幕区现在优先显示译文，原文作为辅助上下文显示在上方。右侧字幕记录会展示最近双语片段、语言方向、上下文数量和端到端延迟。

## 实现思路

- 新增 `src/language` 模块，用 `LanguagePair` 描述源语言、目标语言、ASR locale 和翻译模型配置。
- 新增 `src/translation` 模块，包含翻译请求、翻译事件、字幕片段和模拟翻译客户端。
- final ASR 片段触发翻译请求，并携带最近三条字幕作为上下文。
- 翻译事件通过 `segmentId` 绑定原始 ASR 片段，为后续字幕修订能力预留稳定标识。
- README 继续以中文产品使用说明更新，说明当前双语字幕体验和环境变量。

## 验证方式

- 运行 `npm run build`，确认 TypeScript、Electron 主进程和 Vite 构建通过。
- 运行 Electron smoke test，确认桌面应用可以启动并保持运行。
- 运行 `openspec validate --all`，确认 OpenSpec 变更仍然有效。
- 启动应用后，选择文件模拟或麦克风输入，观察稳定 ASR 片段生成译文字幕。
- 切换语言方向后再次启动输入，确认字幕方向随语言对变化。

## 范围说明

本次只实现结构化语言对、模拟翻译客户端、上下文翻译请求、译文事件和双语字幕展示。字幕修订、悬浮窗口和 TTS 会在后续独立变更中完成。
