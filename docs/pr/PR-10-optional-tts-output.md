# Add optional TTS output

## 功能描述

本次变更新增可选译文语音播报。用户可以在主工作台勾选“译文播报”，稳定的译文字幕会进入本地播放队列，并支持暂停、继续和停止。

语音播报默认关闭。关闭播报会停止当前朗读并清空队列，字幕显示、字幕修订和悬浮字幕同步会继续工作。

## 实现思路

- 新增 `src/tts/types.ts`，定义 TTS 状态、队列项和会话状态。
- 使用浏览器 `speechSynthesis` 作为本地播报能力，优先保证 demo 可运行。
- 只将非临时的稳定字幕加入播报队列，使用字幕 ID 和版本号避免重复播报。
- 主工作台新增译文播报开关、暂停/继续、停止播报和可见队列状态。
- TTS 状态加入底部状态条，便于确认当前是关闭、排队、播报、暂停或异常。

## 验证方式

- 运行 `npm run build`，确认 TypeScript、Electron 主进程和 Vite 构建通过。
- 运行 Electron smoke test，确认桌面应用可以启动并保持运行。
- 运行 `openspec validate --all`，确认 OpenSpec 变更仍然有效。
- 在桌面应用中开启译文播报，使用文件模拟触发稳定字幕，确认队列状态变化。
- 关闭译文播报后继续观察字幕和悬浮字幕，确认字幕链路保持可用。

## 范围说明

本次只实现本地可选 TTS 队列和播放控制。README 完整交付、演示脚本、视频材料和最终提交检查会在后续独立变更中完成。
