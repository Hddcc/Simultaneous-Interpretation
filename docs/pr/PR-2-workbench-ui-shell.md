# PR 2 - 主工作台 UI 壳

## 标题

新增桌面端同声传译主工作台 UI 壳

## 功能描述

本 PR 将初始启动页替换为主工作台界面，为后续音频采集、ASR、翻译、字幕修订和悬浮字幕窗口提供布局基础。

当前界面包含：

- 顶部音频源、语言方向和会话控制区
- 中央原文/译文双行字幕展示区
- 右侧会话历史占位列表
- 底部音频状态、ASR、翻译队列、延迟和 TTS 状态条

## 实现思路

- 使用 React 组件直接组织静态工作台结构。
- 使用 CSS Grid 和 Flex 布局适配桌面窗口和较窄窗口。
- 使用中文界面文案和可访问表单标签。
- 保留静态占位状态，后续 PR 再接入音频、ASR 和翻译数据。
- 将 README 改为中文，并在 OpenSpec 文档中同步 README 中文撰写约定。

## 验证方式

- `npm.cmd run build`
- Electron smoke test
- 检查主窗口不会提前退出
- 检查 README 和 PR 模板已改为中文

## 变更范围

本 PR 只覆盖主工作台 UI 壳和 README 中文撰写约定。实际音频采集、ASR、翻译、字幕修订、悬浮字幕窗口和 TTS 将在后续 PR 实现。
