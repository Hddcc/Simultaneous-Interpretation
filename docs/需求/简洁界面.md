> **项目名称**：声桥轻量版（LinguaBridge Lite）
>
> **目标**：将现有“声桥”客户端重构为轻量级同传工具，保留核心功能，简化界面，增强历史整合与多端支持。
>
> **核心原则**：
>
> - 
>
>   ✅ 速度只快不慢（优于或等于原版）
>
> - 
>
>   ✅ 中英互译功能必须保留
>
> - 
>
>   ✅ 支持原客户端所有音频源（系统音频、麦克风等）
>
> - 
>
>   ✅ 历史翻译需整合、可回溯、不丢失
>
> - 
>
>   ❌ 删除冗余UI（如左侧菜单、诊断、设置、重试按钮等）
>
> - 
>
>   ❌ 不再显示“已定稿”“队列拥塞”等技术标签

------

## 一、核心功能需求

### 1.1 同声传译核心能力（不可删减）

| 功能项     | 要求                                                         |
| ---------- | ------------------------------------------------------------ |
| 翻译方向   | 支持 `中文 → 英文`、`英文 → 中文` 两种模式，可切换           |
| 翻译速度   | ≥ 原版（1013ms），理想目标 ≤ 800ms（如有优化空间）           |
| 音频源支持 | 保留原客户端所有音频源：系统音频、麦克风、文件等（按需列出） |
| 实时显示   | 原文 + 译文同步显示，译文需加粗/高亮，便于快速阅读           |
| 暂停/继续  | 保留“停止同传”按钮（可更名为“暂停”），支持随时恢复           |

> ✅ **注意**：翻译延迟必须控制在可接受范围内（<1s），避免影响使用体验。

------

### 1.2 历史记录整合（核心痛点解决）

> ❗当前问题：历史记录“一句句散开”，无法整合上下文，用户找不到之前翻译的内容。

#### ✅ 重构方案：

- 

  **历史记录模块**：

  - 

    位于主界面下方或侧边（可折叠），默认收起，点击展开。

  - 

    每条记录包含：

    - 

      时间戳（如 `00:15.750`）

    - 

      原文（英文/中文）

    - 

      译文（对应语言）

    - 

      状态标记（可选：`已修订` / `自动翻译`）

  - 

    支持**按时间倒序排列**，最新在上。

  - 

    支持**一键复制整段历史**（或导出为文本）。

  - 

    支持**搜索关键词**（可选，增强可用性）。

- 

  **上下文整合**：

  - 

    当前翻译行上方显示“最近3条历史记录”（可配置），帮助用户理解语境。

  - 

    支持“合并连续语句”功能（如连续两句英文→中文，可自动合并为一段）。

------

## 二、界面设计（极简工具风）

> ✅ 目标：像“悬浮窗”或“小工具”，不占屏幕，不打扰用户。

### 2.1 主界面布局（建议）

```
┌──────────────────────────────────────────────┐
│  [语言方向：英文→中文 ▼]  [暂停]  [设置⚙️] │
├──────────────────────────────────────────────┤
│                                              │
│   But Jonathan insisted on paying, so he…    │
│   **但乔纳森坚持要付款…**                    │
│                                              │
└──────────────────────────────────────────────┘
        ↓ 下方可折叠历史面板（默认收起）
```

- 

  **顶部控制栏**：

  - 

    语言方向下拉框（中英互译）

  - 

    “暂停”按钮（原“停止同传”）

  - 

    “设置”图标（仅保留必要选项：音频源、字体大小、主题）

- 

  **主显示区**：

  - 

    原文（灰色/小字号）

  - 

    译文（加粗/大字号/深色，突出显示）

  - 

    无“已定稿”“ms延迟”等技术标签

- 

  **历史面板**（可折叠）：

  - 

    显示最近10条翻译记录（可滚动）

  - 

    每条带时间戳 + 原文 + 译文 + 状态

  - 

    支持“清空历史”、“导出为TXT”

------

## 三、多端支持（与原客户端一致）

> ✅ 必须支持原客户端所有运行环境：

| 平台    | 支持要求                                     |
| ------- | -------------------------------------------- |
| Windows | 支持系统音频、麦克风、文件输入               |
| macOS   | 同上                                         |
| Linux   | 如需支持，需注明（可选）                     |
| Web     | 如计划上线Web版，需支持浏览器麦克风+系统音频 |

> ✅ 音频源切换需在设置中保留，但界面简化（下拉菜单即可）。

------

## 四、技术约束 & 优化建议

### 4.1 性能要求

- 

  翻译延迟 ≤ 1000ms（理想 ≤ 800ms）

- 

  内存占用 ≤ 200MB（轻量级工具）

- 

  启动时间 ≤ 3s

### 4.2 重构建议

- 

  使用轻量级框架（如 Tauri / Electron + React/Vue 精简版）

- 

  移除不必要的模块（诊断、重试、队列拥塞提示）

- 

  历史记录使用本地存储（IndexedDB / localStorage），无需后端

- 

  支持快捷键（如 Ctrl+Space 暂停，Ctrl+H 查看历史）
