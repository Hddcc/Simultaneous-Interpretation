# 声桥 LinguaBridge 演示视频提交入口

本页用于记录演示视频交付信息。录制完成后，可选择以下任一方式提交：

- 将视频文件放在 `docs/demo/` 目录，例如 `docs/demo/simultaneous-interpretation-demo.mp4`。
- 将视频上传到公开可访问的位置，并在下方填写链接。

## 视频信息

- 视频文件：待录制后补充。
- 公开视频链接：待录制后补充。
- 建议时长：3 到 5 分钟。
- 建议分辨率：1280x720 或 1920x1080。

## 必须覆盖的演示点

- 系统音频、麦克风或文件模拟至少一种输入方式。
- 英语转中文。
- 中文转英语。
- 字幕修订。
- 悬浮字幕窗口。
- 可选译文语音播报。
- README 中的运行方式和依赖归属。

## 录制检查

- 字幕内容清晰可读。
- 悬浮字幕窗口在其他应用上方可见。
- 语音播报开关、暂停和停止状态可见。
- 视频中没有展示真实 API Key、私人路径或敏感窗口内容。
