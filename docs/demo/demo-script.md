# 声桥 LinguaBridge 演示脚本

本脚本用于录制项目演示视频，建议时长控制在 3 到 5 分钟。录制前请先运行：

```bash
npm install
npm run dev
```

## 准备内容

- 一段英文技术分享或课程音频，也可以使用任意本地音频/视频文件进行文件模拟。
- 一段中文语音或中文视频，用于展示中文转英文。
- 系统麦克风权限已允许。
- 系统语音播报可用。

## 镜头顺序

### 开场

展示主工作台，说明声桥 LinguaBridge 面向会议、网课、技术分享、视频播放和跨语言通话场景。

### 文件模拟

1. 音频源选择“文件模拟”。
2. 点击“选择本地文件”。
3. 选择一段音频或视频。
4. 点击“开始”。
5. 展示中央字幕、右侧字幕记录和底部状态条开始更新。

### 英语转中文

1. 语言方向选择“英语 -> 中文”。
2. 保持文件模拟或麦克风输入运行。
3. 展示原文、译文、延迟和上下文信息。

### 中文转英语

1. 切换语言方向为“中文 -> 英语”。
2. 重新开始输入。
3. 展示英文译文字幕。

### 字幕修订

1. 观察字幕从临时版本更新为稳定版本。
2. 展示右侧记录中的版本号和修订原因。
3. 指出最近字幕会原地修正，旧字幕保持可读。

### 悬浮字幕

1. 点击“打开悬浮字幕”。
2. 切换紧凑、标准或宽屏尺寸。
3. 切换左上、右上、左下或右下位置。
4. 将主应用放到后台或切换到其他窗口，展示悬浮字幕仍可阅读。

### 语音播报

1. 勾选“译文播报”。
2. 等待稳定译文进入队列。
3. 展示“播报中”“排队中”等状态。
4. 点击“暂停播报”“继续播报”“停止播报”。
