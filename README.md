# Simultaneous Interpretation

Simultaneous Interpretation 是一款桌面端 AI 同声传译助手，面向会议、网课、技术分享、视频播放和跨语言通话场景。用户启动应用后，可以选择音频来源，并在桌面窗口中查看实时字幕、输入状态和会话记录。

## 适用场景

- 观看英语技术分享、公开课、国际会议或产品发布会。
- 参加腾讯会议、线上讲座、远程面试等实时交流场景。
- 播放本地音频或视频，用文件模拟实时输入流程。
- 后续接入系统音频、麦克风、ASR 和翻译服务后，用于生成中英双语字幕。

## 当前版本

当前版本完成了桌面应用基础体验：

- 主工作台：包含音频源、语言方向、开始/暂停控制、字幕展示区、输入记录和状态条。
- 音频源选择：支持在“系统音频”“麦克风”“文件模拟”之间切换。
- 文件模拟：可选择本地音频或视频文件，并按 500 ms 间隔生成带时间戳的模拟音频块。
- 状态反馈：显示当前输入源、输入状态、音频块数量、模拟音量和语言方向。
- 中文界面：产品说明、主要界面文案和 PR 模板均使用中文表达。

## 快速体验

1. 安装依赖：

```bash
npm install
```

2. 启动开发模式：

```bash
npm run dev
```

3. 在应用顶部选择“文件模拟”。

4. 点击“选择本地文件”，选择一段音频或视频。

5. 点击“开始”，观察右侧输入记录和底部状态条。

## 界面说明

### 顶部控制区

- 音频源：选择系统音频、麦克风或文件模拟。
- 语言方向：选择英语转中文或中文转英语。
- 开始：启动当前音频源流程。
- 暂停：暂停文件模拟输入。

### 实时输入区

中央区域显示当前输入源说明、已选择文件、错误提示和最近音频块时间戳。后续 PR 会在这里接入实时原文和译文字幕。

### 输入记录

右侧记录最近生成的音频块，包括时间戳、序号、文件名、采样率、时长和模拟音量。该区域用于验证文件模拟输入已经进入统一音频流契约。

### 底部状态条

底部展示当前音频源、输入状态、音频块数量、音量和语言方向。后续会继续扩展 ASR、翻译队列、延迟和 TTS 状态。

## 开发运行

技术栈：

- Electron：桌面应用壳
- React：渲染层 UI
- Vite：开发服务器与构建工具
- TypeScript：类型系统

构建并运行本地构建产物：

```bash
npm run build
npm start
```

如果在特殊终端环境中 Electron 被当作普通 Node 进程启动，请先清除 `ELECTRON_RUN_AS_NODE` 后再启动应用。

## 环境变量

后续接入 AI 服务时，请复制 `.env.example` 为 `.env`，并在本地填写 API Key。

```bash
copy .env.example .env
```

真实密钥只保存在本地环境中，请勿提交到仓库。
