# Simultaneous Interpretation

Simultaneous Interpretation 是一款桌面端 AI 同声传译助手，面向会议、网课、技术分享、视频播放和跨语言通话场景。用户启动应用后，可以选择音频来源，并在桌面窗口中查看实时字幕、输入状态和会话记录。

## 适用场景

- 观看英语技术分享、公开课、国际会议或产品发布会。
- 参加腾讯会议、线上讲座、远程面试等实时交流场景。
- 播放本地音频或视频，用文件模拟实时输入流程。
- 通过系统音频、文件模拟或麦克风输入验证实时音频链路，后续接入 ASR 和翻译服务后生成中英双语字幕。

## 当前版本

当前版本完成了桌面应用基础体验：

- 主工作台：包含音频源、语言方向、开始/暂停控制、字幕展示区、输入记录和状态条。
- 音频源选择：支持在“系统音频”“麦克风”“文件模拟”之间切换。
- 系统音频采集：可刷新桌面或窗口来源，尝试捕获电脑正在播放的声音。
- 文件模拟：可选择本地音频或视频文件，并按 500 ms 间隔生成带时间戳的模拟音频块。
- 麦克风采集：可刷新设备列表、选择麦克风，并将输入转换为带时间戳的音频块。
- 实时语音识别：将音频块送入流式 ASR 客户端，展示 partial 和 final 原文片段。
- 状态反馈：显示当前输入源、输入状态、音频块数量、ASR 配置、识别延迟、音量和语言方向。

## 快速体验

1. 安装依赖：

```bash
npm install
```

2. 启动开发模式：

```bash
npm run dev
```

3. 在应用顶部选择“系统音频”“文件模拟”或“麦克风”。

4. 使用系统音频时，点击“刷新来源”，选择一个屏幕或窗口来源。

5. 使用文件模拟时，点击“选择本地文件”，选择一段音频或视频。

6. 使用麦克风时，点击“刷新麦克风”，选择可用设备。

7. 点击“开始”，观察右侧输入记录和底部状态条。

## 界面说明

### 顶部控制区

- 音频源：选择系统音频、麦克风或文件模拟。
- 语言方向：选择英语转中文或中文转英语。
- 开始：启动当前音频源流程。
- 暂停：暂停文件模拟输入。

### 实时输入区

中央区域显示当前输入源说明、已选择桌面来源、文件或麦克风设备、错误提示和最近音频块时间戳。后续会在这里接入实时原文和译文字幕。

### 输入记录

右侧记录最近生成的 ASR 片段，包括时间戳、partial/final 状态、原文、版本号和识别延迟。该区域用于确认系统音频、文件模拟或麦克风输入已经进入实时识别链路。

### 底部状态条

底部展示当前音频源、输入状态、音频块数量、ASR 配置、识别延迟、音量和语言方向。后续会继续扩展翻译队列和 TTS 状态。

### 系统音频说明

系统音频通过 Electron 桌面来源采集能力实现。不同操作系统和不同应用对系统声音共享的支持不完全一致；如果所选来源没有提供音频轨道，界面会显示可恢复的错误提示，用户可以改用麦克风或文件模拟继续验证流程。

## 开发运行

技术栈：

- Electron：桌面应用壳
- React：渲染层 UI
- Vite：开发服务器与构建工具
- TypeScript：类型系统

构建并运行本地构建产物：

```bash
npm run build
npm start
```

如果在特殊终端环境中 Electron 被当作普通 Node 进程启动，请先清除 `ELECTRON_RUN_AS_NODE` 后再启动应用。

## 环境变量

应用默认使用本地模拟 ASR，方便先验证实时体验。需要调整 ASR 配置时，请复制 `.env.example` 为 `.env`，并按需修改：

```bash
copy .env.example .env
```

- `VITE_AI_PROVIDER`：当前默认为 `mock`。
- `VITE_ASR_MODE`：当前默认为 `mock`，用于本地流式识别演示。
- `VITE_ASR_MODEL`：当前默认为 `mock-streaming-asr`。

真实服务密钥只保存在本地运行环境中，请勿提交到仓库。
